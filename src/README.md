# Процедурная версия: приём и обработка заказа (КТ2)

Консольная программа на Python, которая реализует автоматизируемые операции процесса
«Приём и обработка заказа клиента через Telegram-бота сети фастфуд-ресторанов»
и два алгоритма из аналитического раздела отчёта. Версия **процедурная**: только функции
и стандартные структуры данных (`dict`, `list`, `tuple`), собственных классов и глобальных
изменяемых переменных нет. На КТ3 та же задача реализуется объектно-ориентированно на Java.

## Запуск

- Python 3.10 или новее (проверено на 3.12). Внешних библиотек нет, `requirements.txt` не нужен.
- Команда запуска: `python main.py`
- Проверки: `python selftest.py` (должно вывести «Все проверки пройдены»).

Дополнительные параметры: `python main.py --data data/seed.json --scenario data/scenario.json --save result.json`.

## Что внутри

| Файл | Назначение |
|---|---|
| `main.py` | точка входа: читает данные и сценарий, вызывает операции, печатает результат |
| `operations.py` | автоматизируемые операции (функции из таблицы операций в отчёте) |
| `algorithms.py` | алгоритм 1 `calculate_order_total`, алгоритм 2 `estimate_ready_minutes` |
| `storage.py` | чтение и запись данных в JSON |
| `config.py` | константы: статусы, правила скидок, число станций кухни |
| `selftest.py` | проверки на `assert` |
| `data/seed.json` | начальные данные; таблицы и атрибуты совпадают с логической моделью (ER) |
| `data/scenario.json` | входные данные: шаги сценария |

## Соответствие операций и функций

| Операция на BPMN-диаграмме | Функция |
|---|---|
| Зарегистрировать клиента | `register_client()` |
| Проверить состав заказа | `validate_order_lines()` |
| Рассчитать стоимость заказа | `calculate_order_total()` (алгоритм 1) |
| Рассчитать время доставки | `estimate_delivery_minutes()` → `estimate_ready_minutes()` (алгоритм 2) |
| Оформить заказ | `create_order()` |
| Назначить курьера | `assign_courier()` |
| Обновить статус заказа | `update_order_status()` |
| Сообщить статус заказа клиенту | `get_order_status()` |
